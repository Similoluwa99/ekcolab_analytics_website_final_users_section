EKCÖLAB Analytics website

Open index.html in a modern browser. Keep the assets folder beside index.html.
Dashboard icons use the official Hugeicons Free icon font CDN (Stroke Rounded):
https://use.hugeicons.com/font/icons.css
An internet connection is required for the Hugeicons font to load.

The dashboard is a front-end demo with illustrative sample values; no backend is connected.
